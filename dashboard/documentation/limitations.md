# Limitations

- The dataset is synthetic and does not represent actual donors or a real nonprofit organization.
- Source files are excluded from the public repository, so the SQL demonstrates the workflow but cannot reproduce the exact dashboard results without equivalent inputs.
- One merged gift source covers only June 2023-June 2025, while the stable source spans FY21-FY26. Full-data year-over-year comparisons can therefore understate FY25 retention.
- Comparable retention should use the stable-source cohort; it answers a narrower question than full-population retention.
- Synthetic solicitation dates were regenerated to satisfy campaign and attribution rules. They must not be used to infer an optimal real-world solicitation window.
- Campaign-window exceptions can represent legitimate late gifts, processing lag, or source-entry differences and were disclosed rather than automatically removed.
- Conversion and response patterns from synthetic data illustrate analytical methods, not causal fundraising evidence.
